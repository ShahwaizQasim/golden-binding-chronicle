# The Golden Binding Platform

Build a complete website for The Golden Binding using TypeScript, Tailwind CSS, and Framer Motion. Start with the responsive homepage shell, brand typography, exact color palette, primary navigation, and hero section.

Brand & Visual Direction:
The Golden Binding is a premium editorial discovery and recognition platform for books, authors, and publishers.
Tagline: “Recognition for stories made to last.”

Exact Color Palette:
- Primary Brand (Dark Green): #173D35
- Primary Text / Dark Surfaces: #171715
- Soft Background (Warm Paper): #F3EFE6
- Editorial Accent (Oxblood): #6A2727
- Premium Accent (Antique Gold): #B6924A
- Borders / Neutral: #D8D1C4

Typography:
- Headlines: Elegant serif (Cormorant Garamond / DM Serif Display style)
- Body & UI: Clean sans-serif (Inter / Manrope)
- Award marks: Serif with controlled gold detailing

Design feel: Modern literary institution + editorial journal. Clean, spacious, restrained, and prestigious. Avoid generic black-and-gold luxury awards look. Use dark green (#173D35) as the dominant institutional color. Gold only for awards and recognition elements.

Primary Navigation:
HOME • AWARDS • WINNERS • DISCOVER • PUBLISHERS • FEATURES • BLOGS • RESOURCES • ABOUT • SEARCH • ENTER THE AWARDS

Homepage Structure to establish:
1. Hero section
   Headline: “STORIES MADE TO LAST.”
   Subtext: “Recognizing remarkable books, discovering distinctive voices and exploring the people shaping publishing today.”
   Primary CTA: Explore Recognition
   Secondary CTA: Discover Books

Core architectural sections planned:
- Awards (landing, categories, eligibility, judging criteria, process, timeline, fees, FAQ, entry form)
- Winners (current winners, finalists, searchable archive)
- Discover (Books, Authors, New Releases, Emerging Authors, Editors Shelf, New Voices, Genres)
- Publishers (directory + deep profiles for priority publishers)
- Features (Author Spotlight, Publisher Spotlight, Behind the Book, Cover Story, etc.)
- Blogs – The Binding Journal (full blog system with categories)
- Resources (guides, checklists, glossary)
- About (mission, editorial policy, recognition standards, commercial disclosure, press room, contact)
- Functional hooks: Award entry flow, Author & Publisher dashboards, Searchable directories, Winner Toolkit, Newsletter signup
